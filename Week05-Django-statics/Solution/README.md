# Week 05 – Django static files, Bootstrap and pagination
This version adds a student image upload field, media/static configuration, Bootstrap 5 styling (CDN) and a 10-student paginator with an elided page range. `STATIC_URL`, `STATICFILES_DIRS`, `MEDIA_URL` and `MEDIA_ROOT` are configured. The detail page and edit form in Week 06 display uploaded images.
Install dependencies, run `python manage.py makemigrations myApp`, `python manage.py migrate`, `python manage.py seed_students`, then `python manage.py runserver`.
