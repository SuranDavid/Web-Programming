# Week 02 solution – JavaScript
Open `index.html` for the menu-based bill splitter and `todo.html` for the to-do list.
The bill is calculated from added menu items, a selected tip rate and a valid whole-number party size. Validation messages are styled in CSS. The to-do list supports adding, completing and removing tasks and is intentionally not persistent.
For the worksheet's debugger evidence, open `bill.js` in browser developer tools, add a breakpoint on `const subtotal = ...`, calculate a bill, step over the statements and inspect `subtotal`, `tipAmount` and `total`. A real browser screenshot should be captured locally; no debugger screenshot is fabricated in this submission.
